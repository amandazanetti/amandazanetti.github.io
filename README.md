# Amanda Zanetti · Psicanalista

Site de [Amanda Zanetti](https://psi-amandazanetti.com), psicanalista de orientação lacaniana.

Feito com [Jekyll](https://jekyllrb.com/) e o tema [al-folio](https://github.com/alshedivat/al-folio). Publicado no GitHub Pages a cada push na branch `main`.

## Rodar localmente

```bash
bundle install
bundle exec jekyll serve
```

O site fica em http://localhost:4000/.

## Onde editar

- Conteúdo da página: `_pages/about.md`
- Estilo: `assets/css/amanda.css`
- Foto: `assets/img/prof_pic.jpg`
- Título, descrição e demais configurações: `_config.yml`
